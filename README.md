# Cross Channel: Digital Advertising Business Intelligence Platform
An end-to-end digital advertising data pipeline designed to transform multi-channel advertising data into actionable business insights.

## Overview
This project automates the collection, processing, and analysis of digital marketing performance data from multiple advertising platforms. Using API integrations and OAuth 2.0 authentication, the system extracts data from major marketing channels, standardises it, and prepares it for reporting and strategic decision-making.

Supported platforms include:

- Google Ads
- Meta Ads
- Pinterest Ads
- Microsoft Ads
- Google Analytics 4

## Data Pipeline
The solution combines Python-based data extraction and processing scripts with additional JavaScript and R components where required. The pipeline:

1. Authenticates with advertising platforms through secure API connections
2. Collects campaign, performance, and analytics data
3. Cleans and standardises raw datasets
4. Stores processed data in CSV format
5. Feeds reporting and visualisation layers

## Reporting & Analytics
Processed data powers Power BI dashboards that provide:

- Channel-specific performance analysis
- Cross-platform advertising comparisons
- Campaign effectiveness monitoring
- Budget allocation insights
- Key marketing KPI tracking
- Opportunities for optimisation

The dashboards enable marketing teams to evaluate performance trends, identify growth opportunities, and make data-driven investment decisions.

## Business Impact
For an e-commerce organisation operating in a highly competitive digital environment, this platform serves as a central source of truth for advertising performance.

It supports:

- More efficient budget optimisation
- Improved campaign decision-making
- Better understanding of channel contribution
- Faster identification of performance opportunities
- Increased return on advertising investment
